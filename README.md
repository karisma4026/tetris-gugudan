# 구구단 테트리스

스마트폰·태블릿에서 바로 즐기는 웹 반응형 구구단 테트리스.

블록을 쌓다가 **한 줄을 지우면 구구단 문제**가 나오고,
정답을 맞혀야 게임이 이어집니다. 오답이면 계속 다시 풀어야 해요.

## 플레이

https://karisma4026.github.io/tetris-gugudan/

## 조작

- 모바일·태블릿: 화면 아래 버튼 — ◀ ▶ 이동, ↻ 회전, ▼ 빠르게 내리기, ⤓ 한 번에 내리기
- PC 키보드: ← → 이동, ↑ 회전, ↓ 내리기, Space 한 번에 내리기, P 일시정지
- 구구단 문제는 화면 숫자 키패드 또는 키보드 숫자 + Enter로 입력

## 기능

- 10×20 보드, 7종 테트로미노, 다음 블록 미리보기, 착지 예정(고스트) 블록
- 점수·지운 줄·레벨, 맞힌 구구단 개수, 연속 정답
- 한 줄 이상 지우면 즉시 정지 후 2~9단 랜덤 문제
- 오답 시 "다시 풀어보세요!"와 함께 재도전, 힌트 보기 지원
- 일시정지 / 다시 시작, 최고 점수 저장

외부 라이브러리나 CDN 없이 단일 HTML 파일(`index.html`)로 동작합니다.
