# 담우 & 아빠 놀이방

스마트폰·태블릿에서 바로 여는, 담우와 아빠의 놀이 모음집.
홈(`index.html`)에서 두 가지 놀이를 한 번에 골라 들어갑니다.

## 1. 🎮 구구단 테트리스 — [tetris.html](https://karisma4026.github.io/tetris-gugudan/tetris.html)

블록을 쌓다가 **한 줄을 지우면 구구단 문제**가 나오고,
정답을 맞혀야 게임이 이어집니다. 오답이면 계속 다시 풀어야 해요.

- 모바일·태블릿: 화면 아래 버튼 — ◀ ▶ 이동, ↻ 회전, ▼ 빠르게 내리기, ⤓ 한 번에 내리기
- PC 키보드: ← → 이동, ↑ 회전, ↓ 내리기, Space 한 번에 내리기, P 일시정지
- 구구단 문제는 화면 숫자 키패드 또는 키보드 숫자 + Enter로 입력
- 10×20 보드, 다음 블록 미리보기, 착지 예정(고스트) 블록, 점수·레벨, 힌트, 최고 점수 저장

## 2. 📖 루루, 주차하자! — [story.html](https://karisma4026.github.io/tetris-gugudan/story.html)

담우를 위한 자동차 정리·잠자리 그림동화책.
넘기면서 읽는 그림 페이지로 구성되어 있습니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 모음집 홈 (모바일·태블릿 반응형 카드 화면) |
| `tetris.html` | 구구단 테트리스 게임 |
| `story.html` | 그림동화책 〈루루, 주차하자!〉 |

외부 라이브러리나 CDN 없이 각 페이지가 단일 HTML 파일로 동작합니다.
개인정보를 수집하지 않습니다.
